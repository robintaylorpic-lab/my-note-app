Settings & Cloud Sync

Google Drive sync চালাতে হলে নিজের Google Cloud Console থেকে একটি OAuth Client ID বানাও (Drive API enable করে), আর এই পেজের URL-টা Authorized JavaScript origin হিসেবে যোগ করো। এটি ব্রাউজারে file:// হিসেবে খুললে কাজ করবে না — কোনো https:// hosting (যেমন GitHub Pages) দরকার হবে।

চিহ্নিত নেই — Client ID দিয়ে Save করো।
